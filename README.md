# 주식도우미 — 안드로이드 앱

시장 온도, 단기·장기 추천, 급등 후보 스캔, 종목 진단, 내 종목 점검을 휴대폰에서 바로 쓰는 앱입니다.
PC 실행기나 구글 웹앱 설정 없이, 휴대폰이 직접 야후파이낸스·네이버증권 시세를 받아옵니다.

## 설치 (안드로이드)
휴대폰에서 **Releases → 최신 버전 → `stock-helper.apk`** 를 내려받아 설치하세요.
처음 설치할 때 '출처를 알 수 없는 앱 설치' 허용이 필요합니다.

## 주의
기술적 지표와 일부 재무지표를 규칙에 따라 계산한 참고 자료입니다. 뉴스·공시·실적 같은 이벤트는 반영하지 못하며
수익을 보장하지 않습니다. 투자 판단과 책임은 본인에게 있습니다.

## 구조
- `source.zip` — `web/`(앱 화면) + `android/`(안드로이드 앱 껍데기)
- `.github/workflows/build.yml` — 올리면 자동으로 APK를 만들어 Releases에 게시
